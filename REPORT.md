# Урок 6. Авторегрессивный генератор текста

## Задание и цель работы

Обучить декодерный Transformer предсказывать следующий токен и генерировать текст с ограниченным контекстом.

## Использованные методы

Корпус — *Alice’s Adventures in Wonderland* Льюиса Кэрролла, файл carroll-alice.txt из [корпуса Gutenberg в NLTK](https://github.com/nltk/nltk_data/blob/gh-pages/packages/corpora/gutenberg.zip). Каждый десятый абзац отложен для валидации. Токенизатор использует фиксированные UTF-8 байты и специальные токены BOS, EOS и PAD. Обучение токенизатора на корпусе не требуется.

## Реализация

Два блока с четырьмя головами self-attention, ширина 64, синусоидальные позиции из примера преподавателя. Модель использует причинную маску. Для каждого абзаца окна длиной до 128 токенов покрывают все переходы, включая BOS и EOS. PAD исключён из функции потерь. Генерация сохраняет последние 50 токенов контекста по умолчанию, останавливается по EOS и поддерживает поиск по лучу. Чат загружает сохранённые веса.

## Эксперименты

Три эпохи на CPU с AdamW, шагом 0,0001, батчем 8 и seed 42. На каждую эпоху пришлось 127 497 обучающих и 14 955 валидационных переходов. Ошибка и perplexity рассчитаны на уровне байтов.

## Выводы

Валидационная perplexity снизилась с 35,25 до 16,16. На промпте Alice was сэмплирование воспроизводило короткие английские фрагменты, а поиск по лучу многократно повторял the. Три эпохи на одной книге дали начальное моделирование байтовых последовательностей. Связные ответы в записанных примерах не получены.
